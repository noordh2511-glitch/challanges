# لعبة المسابقات الجماعية "سين جيم" (Seen Jeem)

لعبة مسابقات ثقافية جماعية باللغة العربية (RTL) مطابقة لنظام لعبة **سين جيم** الشهيرة، مبنية بـ HTML/CSS/JavaScript صافية بدون أي تعقيدات بناء (Zero-Build)، بحيث تعمل مباشرةً عند فتح الملف أو عند نشرها على أي استضافة ثابتة (GitHub Pages / Netlify / Vercel).

## هيكل المشروع

```text
├── index.html               # الصفحة الرئيسية وهيكل الشاشات والنوافذ
├── src/
│   ├── assets/visuals/      # صور SVG توضيحية جاهزة للأسئلة البصرية (تعمل دون إنترنت)
│   ├── css/
│   │   └── styles.css       # التصميم العصري المتجاوب بطابع برامج المسابقات
│   ├── data/
│   │   └── questions.js     # بنك الأسئلة المنفصل (10 فئات × 6 أسئلة = 60 سؤالاً تشمل «تحدي الصور» و«اربط الصور»)
│   └── js/
│       ├── audio.js         # المؤثرات الصوتية والتنبيهات عبر Web Audio API
│       └── app.js           # منطق اللعبة والمؤقت ووسائل المساعدة والأسئلة البصرية و localStorage
└── README.md
```

## المزايا الرئيسية

1. **شاشة إعداد الجولة (Setup Screen):**
   - تعديل أسماء الفريقين.
   - اختيار 6 فئات بالضبط من بين الفئات المتوفرة مع عرض عدد الأسئلة الجديدة المتبقية في كل فئة.
   - زر **اختيار عشوائي (6 فئات)** وزر **تصفير سجل الأسئلة الملعوبة** مع نافذة تأكيد.
2. **لوحة اللعب الرئيسية (Game Board):**
   - شريط علوي يعرض نقاط الفريقين، أزرار التعديل اليدوي (`+100` / `-100`)، تمييز صاحب الدور، حالة وسائل المساعدة المتبقية لكل فريق، أزرار **تبديل الدور** و **إنهاء الجولة** وكتم الصوت.
   - شبكة 3×2 من 6 بطاقات فئات، لكل بطاقة عمودان (يمين ويسار) بقيم `200 / 400 / 600` بمجموع 36 سؤالاً في الجولة.
3. **نافذة السؤال والمؤقت ووسائل المساعدة:**
   - مؤقت عد تنازلي 60 ثانية يبدأ تلقائياً مع أزرار (إيقاف/تشغيل، وقت الفريق الثاني 10 ثوانٍ، إعادة ضبط) وتنبيه صوتي عبر Web Audio API.
   - 3 وسائل مساعدة تُستخدم مرة واحدة لكل فريق في الجولة (دبل النقاط ×2 لصاحب الدور فقط، جاوب جوابين، اتصال بصديق +30 ثانية) مع إرجاعها تلقائياً عند الضغط على "إلغاء" قبل كشف الإجابة.
   - دعم الصور الاختيارية للسؤال والإجابة بدون ظهور أيقونات صور مكسورة.
   - حفظ أرقام الأسئلة الملعوبة في `localStorage` لمنع تكرارها في الجولات القادمة.
4. **شاشة الفائز (Winner Modal):**
   - تظهر تلقائياً عند انتهاء الأسئلة أو عند الضغط على "إنهاء الجولة" مع عرض الفائز والنتيجة النهائية وزر بدء جولة جديدة.

## طريقة التشغيل والنشر

- **للتشغيل المباشر:** افتح الملف `index.html` مباشرة في أي متصفح حديث.
- **للنشر:** ارفع جميع ملفات المجلد كما هي إلى Netlify أو Vercel أو GitHub Pages.
- **لتعديل أو إضافة أسئلة:** افتح الملف `src/data/questions.js` وأضف أسئلة جديدة بأرقام `id` فريدة (ويمكنك إضافة روابط صور في `questionImage` و `answerImage`).
